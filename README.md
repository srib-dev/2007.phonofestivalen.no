# 2007.phonofestivalen.no

Static recreation of the 2007 [phonofestivalen.no](http://phonofestivalen.no) site from Internet Archive captures, without Wayback Machine toolbar or rewrite URLs.

- Open `index.html` locally or serve this directory with any static file server.
- Pages: `index.html`, `program.html`, `omphono.html`, `frivillig.html`, `bilder.html`.
- Off-site URLs from 2007 are mirrored under `links/`; e-mail links are static pages in `contact/`.
- Re-run `python3 scripts/localize_links.py` after adding new external URLs.
